# Guia rápido para o VS Code

1. Extraia o ZIP.
2. Abra a pasta `V5.2-Modacenter-organizada` no VS Code.
3. Abra o terminal integrado.
4. Rode `npm start`.
5. Acesse `http://localhost:3000`.
6. Para encerrar o servidor, use `Ctrl+C` no terminal.

Para desenvolvimento, mantenha uma cópia de segurança antes de grandes alterações.
